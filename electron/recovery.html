Your saved app data has not been reset. The app needs a completed frontend build or a graphics compatibility restart.

  1. Close the app using its system tray Quit command.
  2. In PowerShell, open the repository folder and run:
    powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1
  3. Run npm start. For a graphics-driver failure, try:
    $env:LAW_DISABLE_GPU="1"; npm start
