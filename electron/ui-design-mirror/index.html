About this copy

Copies use the rendered app and mounted workspaces from the time of capture. To include a newly opened dialog or a lazy-loaded view, open it in the main app, then choose Add current app view. The mirror cannot run app actions. Menu bar styling is a visual proposal; the operating system draws the real native menus.

Drafts, including copied on-screen text, stay in this device’s separate mirror draft. Export contains only requested changes and their targets.
