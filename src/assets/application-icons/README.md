# Application icons

These unmodified product SVGs are bundled locally for Shortcut Registry folders.
They identify the corresponding application and do not require network requests
when the registry opens. Product names and marks belong to Microsoft.

Source: Microsoft's [Fluent UI product icon library](https://developer.microsoft.com/en-us/fluentui#/styles/web/m365-product-icons).

Downloaded October 2, 2026, from the Microsoft CDN:

`https://static2.sharepointonline.com/files/fabric-cdn-prod_20200430.002/assets/brand-icons/product/svg/{product}_48x1.svg`

Products: word, excel, powerpoint, outlook, onenote, teams, onedrive, access.
