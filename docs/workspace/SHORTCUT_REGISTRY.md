# Using the Shortcut Registry

Open **Viewers > Shortcut Registry** directly, or pin it beside Chat. References are organized into collapsible application folders; they start collapsed so Word and Excel stay separate. Create an empty folder with **New application folder**, or add an entry with a new Application name to create its folder automatically. Use a folder's **Add entry** button to prefill its application.

Search by action or keys across folders, then filter by application, category, or type. Matching folders expand while filtering. **Collapse all folders** condenses the page again. Save reference and Copy reference include all matching entries, including entries in collapsed folders. Personal entries and folder names live in app browser storage; clearing that storage removes them. Built-in entries remain read-only.

Application folders show locally bundled icons for Word, Excel, PowerPoint, Outlook, OneNote, Teams, OneDrive, and Access. Short names such as **Word** or **Excel** also work. For another application, click its **Icon** button and choose a PNG, JPG, WebP, or ICO image up to 128 KB. The image is saved locally and remains available after restarting. **Use automatic icon** removes the custom image and restores the matching built-in icon, or the application's initials when no match exists. Icons do not change or appear in exported reference text.

The following is the bundled Microsoft Word starter reference.

## Why marks remain visible

**Microsoft Word** · Word for Windows desktop · English / US keyboard · Layout · Behavior

Some marks can stay visible after Show/Hide is turned off.

**Menu / steps:** File \> Options \> Display \> Always show these formatting marks on the screen.

**Notes:** Individual checked options remain active when Show/Hide is off. Spaces appear as dots; tabs as arrows; paragraph endings as ¶.

[Microsoft Support](https://support.microsoft.com/en-au/word/word-options-display) · Checked 2026-10-02

## No Markup keeps revisions

**Microsoft Word** · Word for Windows desktop · English / US keyboard · Review · Behavior

No Markup hides tracked changes temporarily; it keeps the revisions in the document.

**Menu / steps:** Review \> tracking display \> No Markup.

**Notes:** Accept or reject tracked changes to resolve them before sharing a final copy.

[Microsoft Support](https://support.microsoft.com/en-us/word/accept-or-reject-tracked-changes-in-word) · Checked 2026-10-02

## Accept or reject revisions

**Microsoft Word** · Word for Windows desktop · English / US keyboard · Review · Function

Review each proposed change and decide whether to keep it.

**Menu / steps:** Review \> Accept or Reject. Use Next or Previous to inspect changes without resolving them.

**Notes:** The drop-down menus also offer Accept All Changes and Reject All Changes.

[Microsoft Support](https://support.microsoft.com/en-us/word/accept-or-reject-tracked-changes-in-word) · Checked 2026-10-02
