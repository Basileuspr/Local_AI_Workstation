Keep the history useful

After a meaningful change, run the command below from the repository root, then reload this reader. It saves another observation and updates this reader and the Markdown history.

.\venv\Scripts\python.exe -B .\scripts\capture-app-review.py --note "Describe the completed change"

For new feature notes and fresh verification results, edit review.json. To regenerate the reader without another capture, use --render-only. A capture does not rerun tests or reassess existing findings.

The capture script reads source and dependency metadata. It does not import the app, read chats/model files, run inference, install packages, change settings, commit or push. There is no background automation; record changes when they are finished.

This reader is a repository document, not a new workstation tab. It contains summaries, hashes and links to current source, not historical source bodies. For exact diffs of two uncommitted states, retain commits or separate source backups.
